# Serviços em um só lugar — Nanuque/MG

Portal estático de orientação para serviços públicos digitais, desenvolvido em HTML, CSS e JavaScript para a Atividade Extensionista II (ADS/UNINTER).

## Executar

Abra `dist/index.html` no navegador ou use um servidor HTTP local, por exemplo `python3 -m http.server 8000 -d dist`.

## Escopo

Sete links oficiais, descrições em linguagem simples, busca por assunto, visualização adaptável a celular e computador. O portal não coleta dados pessoais e não representa os órgãos listados.

## Aplicação na comunidade — roteiro para registrar evidência real

1. Mostre o portal a moradores de Nanuque/MG e peça autorização antes de gravar imagem ou voz.
2. Peça para cada participante encontrar um serviço, por exemplo: "Onde posso ver informações sobre aposentadoria?" ou "Onde encontro orientações sobre meu CPF?". Não peça senhas ou documentos.
3. Observe se a pessoa encontrou o cartão correto e conseguiu abrir a página oficial. Pergunte: "Foi fácil encontrar?", "A descrição ajudou?", "O que você mudaria?".
4. Registre data, quantidade de participantes, tarefas realizadas e comentários reais. Grave uma demonstração de até cinco minutos mostrando o portal e sua aplicação à comunidade, respeitando o consentimento.
5. Insira no modelo institucional somente resultados observados, URL do repositório GitHub com este código e URL do vídeo. Não use este README como substituto do relatório final.

## Critérios de conferência

Buscar por `aposentadoria`, `CPF`, `saúde` e `CNH`; verificar todos os links; testar navegação no celular; confirmar legibilidade, foco do teclado e estado de busca sem resultados. Confira os endereços oficiais novamente antes da aplicação.
